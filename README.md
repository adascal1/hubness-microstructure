# hubness-microstructure

This repository contains select key functions used in the data analysis of the prepreint entitled: "Assessing the Functional-Structural Relationship of Connector Hubs in Temporal Lobe Epilepsy". This research article is currently available as a preprint on bioRxiv. This is the link to the research article: https://www.biorxiv.org/content/10.64898/2026.09.25.754445v2. 

This repository contains the script necessary to compute the Hub Disruption Index (HDI).

Other software used for analysis in this manuscript can be found in the following repositories: 

(1) rs-fMRI and DWI processing were performed using micapipe_v0.2.3 : https://github.com/MICA-MNI/micapipe

(2) SParsity-based Analysis of Reliable k-Hubness (SPARK) for rs-fMRI analysis: https://github.com/multifunkim/spark-matlab

(3) Statistical Analysis were performed using BrainStat: https://github.com/MICA-MNI/Brainstat

(4) Spin-tests were performed using BrainSpace: https://github.com/mica-mni/brainspace

(4) Subcortical Visualization was performed using the ENIGMA toolbox: https://github.com/MICA-MNI/ENIGMA

(5) Cortical Plotting was performed using plotROIBoundary: https://github.com/StuartJO/plotSurfaceROIBoundary

(6) Hippocampal Surface Plotting was performed using HippUnfold and HippoMaps: https://hippunfold.khanlab.ca/en/main/ & https://github.com/jordandekraker/hippomaps
